Project Overview

More Than a Signage — An Emotional Companion

This is not just a signage. It is a beverage recommendation machine that reads your emotions. By recognizing colors in real time, it captures your outfit's palette and generates a personalized City Pop style poster within seconds — taking you into a customized dreamscape.

Traditional signage serves static information. We wanted to create something alive — an intelligent installation that resonates emotionally with people.

01
Hardware Architecture

Core Components

Our beverage recommendation machine is precision-integrated from the following core hardware components:

Custom Can-Shaped Shell — Serves as the brand's main visual carrier and physical container, perfectly enveloping all electronics and LED strips into a unified, highly recognizable commercial display terminal.

reServer Edge Computer — Equipped with a high-performance edge processor, running the Node.js serial server and interactive web application for local graphics rendering and multimodal AI (Gemini API) network requests.

Interactive Screen & HD Camera — The screen displays City Pop style interactive UI; the HD camera captures user portraits in real time for intuitive human-machine interaction.

Seeed Studio XIAO ESP32C3 — The underlying execution brain, receiving serial commands from reServer and rendering high-precision dynamic LED light effects.

Custom Carrier Board — Provides dedicated expansion interfaces for XIAO ESP32C3, integrating level-shifting circuits (converting 3.3V GPIO to 5V control logic) and an independent voltage regulation module for stable high-power LED operation.

Built-in Addressable LED Strips — Snap into the structural grooves of the can shell, projecting the user's virtual dreamscape into the physical world through flowing light.

04
Technical Architecture

Hardware-Software Synergy

1. XIAO ESP32C3 & Custom Carrier Board
Based on a RISC-V 32-bit single-core processor, the XIAO offers powerful performance with ultra-low power consumption. The carrier board integrates high-speed bidirectional level-shifting chips (3.3V → 5V) with capacitor filtering and independent voltage regulation, eliminating power ripple interference from LED brightness fluctuations.

2. reServer Edge & Serial Communication
As the "brain" of the signage, reServer connects to the carrier board via USB. A Node.js serial gateway converts AI-identified color auras into lightweight ASCII data frames (e.g. 'R,G,B\n'), writing directly to XIAO ESP32C3 via USB physical serial — enabling near-zero latency cross-platform synchronization.

3. Non-Blocking LED State Machine
The XIAO runs C++ based non-blocking firmware using millis() timer polling instead of delay(). This allows the main board to render "comet tail" and "rainbow" algorithms at high speed while scanning the serial buffer at microsecond intervals — ensuring instant, smooth color transitions.

4. Multimodal AI & Generative Posters
The system calls Gemini's multimodal API: one channel for visual color recognition, another for generating 3:4 ratio retro Cel animation style posters via customized style prompts — perfectly suited for the HD interactive screen.
